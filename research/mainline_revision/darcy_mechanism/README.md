# Darcy 数据版机制验证

**2026-10-26 已完成：48次调参、30条正式训练、60个配对预算点，预算及训练后一致性检查全部通过。当前梯度评分未显示稳定独立增量，停止作为论文主线。** 先读[最终决策](interpretation.md)，完整数字见[实验报告](results_report.md)；以下保留预注册实验设计。

本轮检验三个问题：较长调参后原数据版能否保持优势；梯度评分是否优于相同购买率下的随机和场误差评分；收益是否能够由粗标签预训练后高精度微调解释。此前结果保留在 darcy_optimized，本目录不覆盖旧实验。

八组方法为原数据自适应、固定率梯度评分、固定率随机购买、固定率场误差评分、粗标签预训练后微调、全高精度、纯物理校正、作者 MLMC。三个固定率版本共用教师、重要性纠正目标和平均购买概率0.25，只改变样本间分配；原数据版继续按方差和实测成本自适应总购买率。固定率组不计算不使用的全局方差审计，梯度与场误差各支付自身真实评分成本。购买总数可能因缓存、采样历史和训练步数而不同。

每方法6次调参，每次180秒：常规组搜索0.002至0.064的6个学习率；预训练组联合搜索0.004、0.008、0.016和30、120秒切换点，同样6次。每组正式训练3种子，每条1200秒并记录300秒前缀。另对原数据、固定率三组和全高精度统一采用0.008学习率；与选择配置重合时复用轨迹。总计48次调参、24至39条正式轨迹。计算时限包含训练输入构造、标签求解、教师、评分、优化、验证和内存检查点；保留15秒验证收尾。初始验证也计时，数值发散保留有效检查点并记录，不删除差种子。

测试使用新种子39191和39291，分别256个ID和128个OOD输入；模型选择仅看原公共验证集。全部计时训练在同一机器上单CPU线程串行运行，配置与源码在protocol.json冻结。对照结果无法证明梯度评分独立收益时，不以已有组件组合自动推荐立项。是否进入第二个真实PDE，由完整机制比较决定。
