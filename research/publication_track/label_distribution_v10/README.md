# Frozen 512-input numerical diagnostic

run.py writes protocol and parameters before solving, checks 28 original source hashes, and refuses to overwrite an existing protocol. Use a fresh directory to rerun. The existing project Python environment supplies NumPy, SciPy and PyTorch. analyze.py recomputes errors from saved arrays and plots with Matplotlib. Each bootstrap resample keeps an input's label triple paired; uncertainty pertains to IID coefficient inputs, not network seeds.

All labels are projected to 129x129; archived float32 scaling is preserved and norm arithmetic is float64. No test outcomes, tuning, trained-model evaluation or new training. Diagnostic expenses are additional to original construction budgets. Do not combine the different-grid historical six-input stress screen with this sample.
