\section{Matched-learning-rate follow-up}

The prior FNO comparison selected learning rates 0.002 for coarse targets and 0.008 for corrected targets. We therefore fix both rates in a complete two-by-two comparison of coarse32 and corrected32. Each cell has five new paired training pools and optimization seeds, with a fresh validation/ID/OOD reference set (32/128/64 inputs). Twenty trajectories run from scratch to 600 seconds and contain dependent 120/180/360-second checkpoints. All numerical targets, architectures, optimizer schedules, initialization labels, sensor/output grids, and accounting rules use the frozen follow-up engine. There is no new hyperparameter search or test-based rate selection; both rate-specific outcomes are reported. The existing DeepONet coarse/corrected comparison already matched rate 0.008 and is not rerun.

\paragraph{Rate sensitivity.} The difference between the two rate-specific correction contrasts is reported without choosing a preferred rate after testing.

At 180 s, the ID difference-of-differences (rate 0.008 minus 0.002) is -1.288 percentage points, approximate interval [-3.831, 1.254].

At 600 s, the ID difference-of-differences (rate 0.008 minus 0.002) is -1.712 percentage points, approximate interval [-3.526, 0.101].

Matching the rate removes this particular configuration difference but does not isolate correction bias from its numerical cost and the resulting number of updates. These remain budget-policy comparisons, not a pure causal estimate of label fidelity. New evaluation inputs prevent pooling these runs with earlier cohorts. All adverse outcomes remain in the release.
